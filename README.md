# Socialmix

Socialmix is event infrastructure for creators, podcast hosts, live-show organisers and community leaders.

It supports paid registration, attendee check-in, random groups of exactly three, host-defined missions, a mission deadline that can be after the event, evidence submission, host verification, participant ratings and payout states.

It deliberately has no social feed, attendee direct messages, AI matching or social-media scraping.

## Demo flow

1. Buy the test ticket.
2. Switch to Host and create/release mixes.
3. Switch to Attendee to reveal the group and mission.
4. Check in.
5. Switch to Host and mark the event complete.
6. Switch to Attendee and submit mission evidence.
7. Switch to Host and verify it.
8. Switch to Attendee and rate mix partners.

Demo state persists in browser localStorage. Payments and payouts are test-state simulations only.

Live demo: https://socialmix-live.vercel.app
